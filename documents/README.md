# Forge 文档

Forge 以 Bazel 管理构建与交付，支持原生 C++、CMake、Conan 依赖、私有运行闭包和 Debian/测试制品。

## 文档约定

- 需求规定必须满足的行为；技术设计明确实现机制及边界，不能用边界说明降低发布要求。
- API 参数与命令对应公开规则。完整教学工程以示例规划中的实施状态为准。
- 构建成功、ELF 检查、解包运行、干净目标运行和跨机缓存各有独立证据，不能互相替代。
- 执行结果写入每次运行的报告，不在规范中维护容易失真的固定通过数量。
- 变更配置、接口或交付语义时，同步更新对应指南、FR/TC 映射与实际测试。

交叉编译尤其要区分编译器默认 sysroot、CMake 查找根和部署运行库路径。`/opt/eros` 加载器约定本身不是完整 SDK/glibc 一致性证明。
